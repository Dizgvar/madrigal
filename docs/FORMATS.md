# Договорённости

Структуры данных: lab/models.py (импортировать только оттуда).
Номера пакетов с 1, смещения с 0, диапазоны [start, end). Время в микросекундах.
Неизвестное это Span(kind="gap", data=None), никогда не нули.
Ожидаемые ошибки: LabError или CaptureError с кодом. Без except: pass.
Хэши: SHA-256, строчный hex. Новые зависимости только через капитана.
